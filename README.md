# MSGN · Marcos Galián — Sitio web

Landing page de MSGN (Marcos Galián · Experiencias & Producciones), agencia de
comunicación, producción y vinculación en Neuquén y la Patagonia Argentina.

## DEPLOY
www.msgn.com.ar

## Stack

- **React 19** + **Vite**
- **Tailwind CSS**

## Variables de entorno
.env

## Estructura

- `src/components/` — componentes de cada sección (Hero, Portfolio, Contact, etc.)
- `api/contact.js` — función serverless que envía los mails vía Resend
- `public/` — assets estáticos, sitemap y robots.txt
